    Overview

    Provider subscriptions

    Add one subscription per simultaneous stream you want (e.g. 2 subs = 2 screens). All must be the same provider.

    Import a curated playlist

    Bulk-import from an existing .m3u. Matches by provider stream id, so a playlist from any subscription works. Sync first.

    Xtream connection

    Add these to any Xtream Codes client — Dispatcharr (VOD Scanning ON, max connections 1), a Jellyfin Xtream plugin, TiviMate, etc. One account per subscription.

    Downstream sync

    After curating, refresh the curated account in Dispatcharr, then run the Jellyfin Xtream-library sync and refresh only the libraries you pick — in sequence, from one button.

    Scheduled auto-sync

    Automatically pull the provider catalogue on a schedule. A run missed while the app was offline is skipped — the next slot is used.
